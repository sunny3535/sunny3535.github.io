데이터 전처리 실습 시트

결측값, 이상값, 스케일링, 범주형 인코딩을 직접 적용해보세요.

전처리 도구

1. 결측값 처리

우측 표에서 붉은색으로 표시된 결측값(NaN) 셀을 클릭하여 처리 옵션을 선택하세요.

2. 이상값 처리

우측 표에서 노란색으로 표시된 이상값 셀을 클릭하여 처리 옵션을 선택하세요.

3. 스케일링

수치형 데이터의 범위를 조정합니다.

4. 범주형 인코딩

문자형 데이터를 기계가 이해할 수 있는 숫자로 변환합니다.
