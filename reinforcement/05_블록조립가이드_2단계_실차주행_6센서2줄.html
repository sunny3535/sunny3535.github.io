0. 이 단계의 핵심 개념 — 전이(Sim2Real)의 비결 🔑

1단계에서는 화면 속 자동차가 안전하게 수천 번 연습하며 "선 따라가는 법"을 배우고, 그 실력을 Q테이블(두뇌) JSON 파일로 저장했어요. 이번 2단계는 그 두뇌를 진짜 자동차에 그대로 옮겨 달리게 하는 단계예요. 이걸 Sim2Real(시뮬 → 리얼)이라고 불러요.

이 문서는 09_2단계_실주행_6센서2줄_v7 파일을 처음부터 따라 조립하는 안내서예요. 블록 하나하나를 "어디에 · 어떤 값으로" 끼우는지 순서대로 보여줄게요.

🔑 전이의 비결 — "똑같은 6센서 변환 → 똑같은 상태 → Q테이블 그대로 작동"

어떻게 화면에서 배운 두뇌가 진짜 자동차에서 통할까요? 비밀은 딱 하나예요. 1단계와 완전히 똑같은 '6센서 변환' 블록을 쓰는 것!

🖥️ 1단계 (시뮬)

화면 센서 6개가 검은색에 닿았나로 100/0 → 상태 암호 FL_FC_FR_L_C_R

🚗 2단계 (실차)

카메라 화면을 6영역으로 나눠 선이 있나로 0/1 → 똑같은 상태 암호 FL_FC_FR_L_C_R

▼ 입력만 바뀔 뿐, 상태 암호는 6자리로 완전히 같다 ▼

그래서 상태가 "0_1_0_0_1_0"이면 시뮬이든 실차든 똑같은 상태로 인식돼요. 상태가 같으니 1단계에서 배운 Q테이블(어떤 상태에서 무슨 행동이 좋은지 적은 표)이 그대로 작동해요. 이게 Sim2Real의 마법이에요.

한 줄 요약  변환 블록이 같다 → 상태가 같다 → 두뇌가 그대로 통한다. 나머지(눈·다리·안전장치)는 "진짜 세상"에 맞춰 옷만 갈아입는 것이에요.

🧩 오프보드 컴퓨팅 — 눈·뇌·다리를 셋으로 나눈다

진짜 자동차엔 무거운 컴퓨터를 실을 수 없어요. 그래서 역할을 3개로 나눠 무선으로 협력해요.

👁️ 눈 = ESP32캠

자동차에 달린 작은 카메라. 바닥의 선을 촬영해 무선으로 PC에 보내요. (초록 블록)

🧠 뇌 = PC (브릭셀AI)

영상을 6영역으로 나눠 상태를 만들고 Q테이블로 행동을 결정. 무거운 계산은 여기서. (보라 블록)

🦵 다리 = 우노카

PC의 명령대로 그린긱 서보로 바퀴를 굴리는 진짜 자동차 본체. (빨강 블록)

눈이 본 것 → 뇌가 결정 → 다리가 실행. 이 셋이 매 순간 무선으로 주고받으며 달려요.

📌 상태 암호 다시 보기 — "FL_FC_FR_L_C_R" (6자리)

상태는 0 또는 1이 6개 붙은 암호예요. 각 자리가 카메라 영역 하나이고, 1=선을 봄, 0=선 못 봄이에요. 앞 3자리(FL·FC·FR)는 윗줄=먼 곳=미래(커브 예측), 뒤 3자리(L·C·R)는 아랫줄=가까운 곳=현재 위치예요.

FL_FC_FR _ L_C_R
└─ 윗줄(미래·커브 예측) ─┘ └─ 아랫줄(현재 위치) ─┘

6자리라서 이론상 2⁶ = 64가지 상태가 나올 수 있어요. 행동은 딱 3개(0=직진, 1=좌회전, 2=우회전)예요. 이 구조가 1단계와 완전히 같기 때문에 두뇌가 전이돼요.

3. 준비 버튼 스크립트 — 눈·다리·뇌를 켠다 🖱️

깃발(🏁)을 누르기 전에, 자동차의 눈(카메라) · 다리(보드) · 뇌(모델)를 차례로 준비시켜야 해요. 각각을 키를 눌렀을 때 블록으로 만들어, 필요할 때 키 한 번으로 실행되게 조립해요.

아래 a키, 스페이스키 스크립트를 각각 조립하세요. 실제 주행 순서는 ①a키(카메라·라인) → ②보드 연결 → ③스페이스키(모델 불러오기) → ④🏁 깃발이에요.

② 보드 연결 — 자동차(다리) 준비

카메라를 켠 다음에는 우노카 자동차 본체를 연결해요. 이 블록은 버튼이나 별도 키로 한 번 실행하면 돼요.

클릭 / 키 — 자동차 보드 연결 · 실제 블록
보드가 연결되면 다음 4장 주행 루프에서 그린긱 서보 전진 블록으로 바퀴를 굴릴 수 있어요. 연결이 안 되면 자동차가 명령을 못 받아 가만히 있어요.

③ 스페이스키 — 학습한 두뇌(모델) 불러오기

이 한 블록이 Sim2Real의 심장이에요. 1단계에서 💾 강화학습 모델 저장하기로 만든 그 JSON 파일(두뇌)을 여기서 불러와요. 시뮬에서 수천 번 연습해 얻은 실력이 그대로 실차의 뇌 속으로 들어가는 순간이에요.
불러오는 파일을 헷갈리지 마세요! 반드시 6센서 2줄로 학습한 1단계 JSON을 불러와야 해요. 3센서(1줄)로 만든 옛날 모델은 상태 암호가 6자리가 아니라서 전이가 안 돼요.

✅ 주행 시작 순서 요약 (이 순서대로!)

① a키 (카메라·라인 세팅) → ② 보드 연결 (다리) → ③ 스페이스키 (두뇌 불러오기) → ④ 🏁 깃발 (주행 시작!)

순서를 지키지 않으면(예: 모델 안 불러오고 깃발) 자동차가 텅 빈 두뇌로 헤매요.

4. AI주행 스프라이트 — 주행 스크립트 🏁

이제 실제로 달리는 뇌를 조립할 차례예요. AI주행 스프라이트에 아래 스크립트 하나를 만들어요. 크게 준비(딱 한 번) + 주행 루프(무한 반복)로 나뉘어요.

🅐 준비 — 깃발 직후 딱 한 번

[ AI주행 ] 🏁 클릭했을 때 · 실제 블록
학습률 0, 탐험률 0인 이유: 학습률 0 = Q테이블을 더 이상 고쳐 쓰지 않음(=배우기 끔). 탐험률 0 = 엉뚱한 시도 없이 늘 최선의 행동만 골라요. 1단계에선 0.2 / 0.3이었지만, 실차에선 이미 다 배웠으니 0 / 0으로 "실전 모드"예요.
시스템 설정 (행동수 3): 뇌에게 "선택지는 3개(직진·좌·우)"라고 알려줘요. 이 숫자가 1단계와 같아야 불러온 Q테이블의 칸이 맞아떨어져요. 0.5초 기다리기는 카메라·보드가 자리 잡을 시간을 주는 거예요.
여기서 학습률·탐험률을 0이 아닌 값으로 두면 실차가 제멋대로 새 행동을 시도하다가 벽에 부딪히거나 배운 실력을 망가뜨려요. 실차 주행은 반드시 0 / 0이에요.

2라인 완전 상실이면 → 마지막방향으로 재탐색

하는 일: 6영역이 전부 0이면 선을 완전히 놓친 거예요. 이때는 행동을 고르지 않고, 방금 전까지 돌던 방향(마지막방향)으로 계속 전진하며 선을 다시 찾아요.

왜 이게 실차에만 있을까? 시뮬은 선을 놓치면 −100 주고 출발점으로 리셋하면 그만이에요. 하지만 진짜 자동차는 리셋이 없어요. 그래서 "왼쪽으로 커브 돌다 놓쳤으면 계속 왼쪽으로, 오른쪽이면 오른쪽으로" 가며 선을 되찾는 실차 전용 안전장치가 필요해요.

1좌회전왼쪽 11 / 오른쪽 20 (왼바퀴 느림 → 왼쪽으로 완만한 호)0.01초
2우회전왼쪽 20 / 오른쪽 11 (오른바퀴 느림 → 오른쪽으로 완만한 호)0.01초
마지막방향은 왜 갱신해? 오른쪽 영역>0.5(선이 오른쪽에 있음)이면 마지막방향=2, 왼쪽 영역>0.5면 마지막방향=1로 기억해 둬요. 그래야 나중에 선을 완전히 놓쳤을 때(2단계 상황) 맞는 쪽으로 재탐색할 수 있어요.
직진은 0.05초, 회전은 0.01초로 지속 시간이 달라요. 직진은 조금 더 길게 밀어 속도를 내고, 회전은 짧게 여러 번 나눠 넣어 과하게 꺾이지 않게 부드럽게 감아요.
회전 블록 뒤에 '정지' 블록을 절대 넣지 마세요. 정지를 넣으면 앞으로 못 나가 제자리에서 빙그르(스핀) 돌며 끊겨요. 자세한 이유는 다음 5장에서!

5. 그린긱 서보 조향 원리 — 전진 호(arc)로 돈다 🚗

이 자동차는 핸들이 따로 없어요. 대신 왼쪽 바퀴와 오른쪽 바퀴의 속도를 다르게 줘서 방향을 틀어요. 이걸 차동(속도차) 조향이라고 해요. 조립할 때 이 원리를 알면 회전 값을 스스로 튜닝할 수 있어요.

🔧 핵심 — "한쪽 바퀴를 느리게 하면, 느린 쪽으로 휜다"

⬆️ 직진 (왼30 / 오30)

두 바퀴 같은 속도 → 똑바로 전진.

↰ 좌회전 (왼11 / 오30… 여기선 오20)

왼쪽을 느리게 → 왼쪽으로 완만하게 휘며 전진.

↱ 우회전 (왼20 / 오11)

오른쪽을 느리게 → 오른쪽으로 완만하게 휘며 전진.

두 바퀴 모두 앞으로(전진) 돌되, 속도만 다르게 → 앞으로 나아가며 부드럽게 도는 "전진 호(arc)"가 돼요.

❌ 하지 말 것 — "제자리 스핀"

만약 한쪽 바퀴를 멈추거나(0) 반대로 돌리면, 자동차는 앞으로 못 나가고 제자리에서 빙그르 돌아요(스핀). 이러면 선을 따라가는 게 아니라 한 자리에서 왔다갔다만 해요.

전진 호 (권장 ✔)제자리 스핀 (금지 ❌)
바퀴둘 다 전진, 한쪽만 느리게한쪽 정지 또는 반대 회전
움직임앞으로 나아가며 완만히 휨앞으로 안 나감, 제자리 회전
주행 느낌끊김 없이 부드럽게 굴러감덜컹덜컹 왔다갔다, 선 이탈
회전 뒤 '정지'넣지 않음정지를 넣으면 스핀처럼 끊김
각 행동(직진·좌·우) 블록 뒤에 '정지' 블록을 넣지 마세요. 무한 반복이 다음 바퀴 명령을 곧바로 내리기 때문에, 정지를 끼우면 매번 멈췄다 출발하며 끊겨요. 서보는 다음 명령이 올 때까지 이전 속도를 유지하므로, 정지 없이 계속 전진 명령만 갱신하는 게 가장 부드러워요.
사람이 자전거 탈 때도, 왼쪽으로 돌려고 멈추지 않고 몸을 살짝 왼쪽으로 기울이며 계속 페달을 밟잖아요? 전진 호가 딱 그 느낌이에요. 멈추지 않고, 속도만 살짝 기울여 방향을 잡는 거예요.

🎚️ 회전 값 튜닝 팁

  • 커브에서 선을 자꾸 놓치면(덜 돎): 느린 쪽 바퀴 속도를 더 낮춰요. 예: 좌회전 왼쪽 11 → 9 (속도차 ↑ = 더 급하게 돎)
  • 지그재그로 흔들리면(과하게 돎): 느린 쪽 바퀴 속도를 조금 올려요. 예: 왼쪽 11 → 14 (속도차 ↓ = 더 완만하게 돎)
  • 전체가 너무 빠르면: 직진 30을 25처럼 낮춰 안정적으로. (단, 좌우 회전 값도 같이 비례해 조절)
값은 바닥 마찰·배터리 전압·바퀴 상태에 따라 달라져요. 위 표의 값(직진 30, 회전 느린쪽 11)을 기준점으로 삼고, 실제 트랙에서 조금씩 바꿔가며 가장 부드러운 값을 찾으세요.

6. 실차 주행 전 체크리스트 & 안전 ✅

📋 주행 전 조립·연결 체크리스트

  • 확장 3개(rlmachine · esp32cam · unocar)를 브릭셀AI에 추가했다.
  • 무대 변수 3개(현재상태 · 행동 · 마지막방향)를 만들었다.
  • a키 스크립트: 에이전트 연결 → 영상 켜기 → 1초 → 라인색 clear·학습 → 대비 0.8 → 6영역 감지(임계 70) → 검정비율 15 → ROI 60 순서로 조립했다.
  • 자동차 보드 연결 블록을 만들었다.
  • 스페이스키 스크립트로 1단계 6센서 JSON 모델을 불러오게 했다.
  • 주행 준비: AI 두뇌 설정 학습률 0 · 탐험률 0, 시스템 설정 행동수 3, 0.5초 기다리기.
  • 주행 루프: 현재상태(6센서 변환) → 라인 상실 복구 → 행동 고르기 → 서보 3행동을 조립했다.
  • 서보 값: 직진 30/30·0.05초, 좌회전 11/20·0.01초, 우회전 20/11·0.01초.
  • 각 행동 뒤에 '정지' 블록을 넣지 않았다(전진 호 유지).

🛟 실차 안전 수칙 — 꼭 지켜요!

✋ 손이 닿는 거리에서

무선 주행이라 자동차가 멀리 튈 수 있어요. 항상 손으로 잡을 수 있는 거리에서 테스트하고, 깃발 중지 버튼을 바로 누를 준비를 하세요.

🧱 바닥·공간 확보

주변에 떨어질 만한 모서리(책상 끝)·부딪힐 물건이 없는 넓고 평평한 바닥에서 하세요. 트랙 주변을 정리해요.

🔋 배터리 확인

배터리가 부족하면 서보 힘이 약해져 회전이 느려지고 값이 안 맞아요. 충분히 충전된 배터리로, 오래 쓰면 중간에 교체·충전하세요.

📷 카메라 하향 고정

카메라는 바닥 쪽(하향)으로 단단히 고정해요. 시뮬의 위에서 내려다보는 방식과 맞아 전이가 잘 되고, 흔들리면 선을 놓쳐요.

😵 자주 겪는 문제 & 해결

이런 일이 생기면원인해결
자동차가 안 움직임보드 연결 안 됨 / 모델 안 불러옴 / 학습률·탐험률이 0 아님이 아니라 연결 순서 문제a키 → 보드 연결 → 스페이스키(모델) → 🏁 순서대로 다시.
계속 0_0_0_0_0_0만 나옴카메라가 선을 못 봄(색 학습 실패·조명·반사)라인색 다시 학습, 대비 0.8 확인, 카메라 하향 고정.
제자리에서 빙글빙글(스핀)회전 뒤 정지 블록이 있거나 한쪽 바퀴가 멈춤정지 블록 제거, 두 바퀴 모두 전진(속도만 다르게) 확인.
커브에서 선을 놓침회전이 덜 됨 / 라인이 너무 굵음느린 쪽 바퀴 속도 더 낮추기. 카메라 살짝 높여 라인을 얇게.
지그재그로 흔들림회전이 과함(속도차 큼)느린 쪽 바퀴 속도 조금 올려 완만하게.
선을 놓치면 멈춰버림라인 상실 복구(마지막방향 전진) 블록 빠짐현재상태=0_0_0_0_0_0일 때 마지막방향으로 전진 블록 확인.

🎯 한 줄 요약 4가지 — 이것만은 꼭!

1️⃣ 전이의 비결 = 똑같은 6센서 변환 → 똑같은 6자리 상태 덕분에 1단계 Q테이블이 실차에서 그대로 작동.
2️⃣ 오프보드 = 눈(ESP32캠) · 뇌(PC) · 다리(우노카)로 나눠 무선으로 협력.
3️⃣ 실차는 배우기 끔 = 학습률 0 · 탐험률 0. 선 놓치면 마지막방향으로 재탐색(리셋 없음).
4️⃣ 부드러운 주행 = 회전은 전진 호(한쪽 바퀴 느리게), 회전 뒤 정지 블록 금지.
여기까지 다 조립했다면, 이제 a키 → 보드 연결 → 스페이스키 → 🏁 순서로 눌러 진짜 자동차를 달리게 해봐요. 컴퓨터에서 배운 두뇌가 진짜 세상에서 선을 따라 부드럽게 달리는 순간, 여러분은 Sim2Real 전이를 직접 성공시킨 거예요! 🚗💨
