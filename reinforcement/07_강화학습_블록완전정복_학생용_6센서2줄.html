0. 강화학습, 처음이지? 걱정 마 🙂

강화학습은 "칭찬과 벌점으로 스스로 배우는 것"이야

혹시 강아지한테 "앉아!"를 가르쳐 본 적 있어? 강아지가 우연히 앉으면 간식(칭찬)을 주고, 엉뚱한 짓을 하면 간식을 안 줘. 그러면 강아지는 간식을 더 받으려고 점점 "앉는 행동"을 스스로 골라. 아무도 "엉덩이 근육을 이렇게 움직여"라고 가르쳐 준 적이 없는데도 말이야.

강화학습(Reinforcement Learning)이 바로 이거야. AI에게 정답을 알려주지 않아. 대신 잘하면 +점수(보상), 못하면 −점수(벌점)만 줘. 그러면 AI는 점수를 더 받으려고 스스로 시행착오를 하면서 "무엇을 해야 좋은지"를 알아내.

게임에서 처음엔 아무것도 모르고 막 죽지만, 계속 하다 보면 "여기선 점프해야 안 죽는구나!"를 몸으로 익히잖아? 그 과정이 바로 강화학습이야. 우리 자동차도 처음엔 선을 못 따라가다가, 수천 번 연습하면 스스로 잘 달리게 돼.

지도학습이랑 뭐가 달라? (딱 한 줄)

종류배우는 방식한 줄 비유
지도학습사람이 정답을 다 붙여준 데이터로 배움 (사진 + "고양이")📖 정답지가 있는 문제집
강화학습직접 해보고 받은 점수로 배움 (정답은 아무도 안 알려줌)🐶 강아지 훈련 (잘하면 간식)

딱 한 줄 차이: 지도학습은 정답을 보고 외우고, 강화학습은 점수를 받으며 스스로 깨달아.

🎯 우리가 이 프로젝트에서 만들 것 (미리보기)

우리 목표는 검은 선(라인)을 스스로 따라 달리는 자동차를 만드는 거야. 그런데 진짜 자동차로 수천 번 연습시키면 배터리도 닳고 부딪혀서 부서져. 그래서 순서를 이렇게 나눠:

🖥️ 1단계 — 컴퓨터 속에서 학습

화면 속 자동차가 안전하게 수천 번 시행착오를 하며 "선 따라가는 법"을 배워. 배운 내용은 Q테이블이라는 표에 저장돼. (파일: 09_1단계_강화학습_6센서2줄_v8)

🚗 2단계 — 진짜 자동차로 전이

컴퓨터에서 배운 그 표(두뇌)를 진짜 자동차에 그대로 옮겨 달려. 이걸 Sim2Real(시뮬 → 리얼)이라고 해. (파일: 09_2단계_실주행_6센서2줄_v7)

이 교재는 두 단계에 나오는 블록을 하나하나 "무슨 일을 하는지 · 왜 필요한지"까지 뜯어봐. 다 읽으면 너도 강화학습 자동차를 완전히 이해하게 될 거야!

1. 준비물 · 용어 30초 사전 📚

어려운 말이 나와도 당황하지 마. 여기 있는 7개 단어만 알면 이 교재를 끝까지 읽을 수 있어. 지금은 가볍게 훑고, 나중에 블록에서 다시 만나면 여기로 돌아와서 확인해.

① 상태 (State)

"지금 상황"을 숫자로 요약한 것. 우리 자동차에선 센서 6개가 검은 선 위에 있나 없나를 모은 암호야. 예: 1_0_0_0_1_0. → 자동차가 "지금 보는 화면" 같은 거.

② 행동 (Action)

자동차가 고를 수 있는 선택지. 여기선 딱 3개: 0=직진, 1=좌회전, 2=우회전. → 게임 컨트롤러의 버튼 같은 거.

③ 보상 (Reward)

행동의 결과로 받는 점수. 잘하면 +점수, 못하면 −점수. 이 점수를 우리가 어떻게 설계하느냐가 강화학습의 핵심이야!

④ Q테이블 (Q-table)

"어떤 상태에서 어떤 행동이 얼마나 좋은가"를 적은 점수표. AI의 뇌이자 공부 노트야. 학습이 끝나면 이 표를 파일로 저장해.

⑤ 에피소드 (Episode)

한 판(round). 자동차가 선을 완전히 놓치거나 벽에 부딪히면 한 판이 끝나고 출발점으로 돌아가. 그게 1 에피소드.

⑥ 학습률 (α, 알파)

한 번 경험으로 얼마나 크게 배울지. 우리 값은 0.2. → "한 번 데인 걸 20%만큼 반영"한다는 뜻. 크면 빨리 배우지만 불안정해.

⑦ 탐험률 (ε, 엡실론)

가끔 일부러 아무 행동이나 해보는 비율. 배울 땐 0.3(30%), 다 배운 뒤 달릴 땐 0. → "늘 가던 길만 갈까, 가끔 새 길도 가볼까"의 비율.

➕ 보너스: 무한 반복

이 모든 게 무한 반복 블록 안에서 계속 돌아가. 상태 보기 → 행동하기 → 점수받기 → 배우기 … 를 쉼 없이 반복하면서 조금씩 똑똑해져.

한꺼번에 외우려고 하지 마! 상태·행동·보상 이 3개만 먼저 확실히 잡으면 돼. "지금 상황을 보고(상태), 무언가 하고(행동), 점수를 받는다(보상)." 나머지는 읽다 보면 자연스럽게 익숙해져.

2. 6센서 2줄이 왜 중요할까? 👀👀

자동차가 선을 따라가려면 먼저 선이 어디 있는지 봐야 해. 그 "눈" 역할을 하는 게 센서야. 예전 버전은 센서가 3개(한 줄)였는데, 이번엔 6개(두 줄)로 늘렸어. 왜 그랬을까?

🔑 핵심 — 윗줄은 "미래", 아랫줄은 "현재"를 본다

🔺 윗줄 3개 (FL · FC · FR) = 미래 예측

자동차에서 더 멀리(far) 있는 센서. "선이 앞으로 어느 쪽으로 휘는지"를 미리 알려줘. → 커브가 오는 걸 미리 감지!

🔻 아랫줄 3개 (L · C · R) = 현재 위치

자동차에 가까운(near) 센서. "선이 지금 바로 앞에 어디 있는지"를 알려줘. → 예전 3센서가 하던 역할.

▼ 윗줄 + 아랫줄을 합치면 ▼

상태 예시    1_0_0 (윗줄=왼쪽)  ·   0_1_0 (아랫줄=가운데)  →  상태 "1_0_0_0_1_0"

먼 곳은 왼쪽으로 휘고, 가까운 곳은 아직 가운데 → "곧 왼쪽 커브가 온다!"는 뜻. 그래서 자동차는 아직 똑바로 갈 때부터 미리 살짝 왼쪽으로 트는 법을 배워. 아랫줄만 봤다면 "가운데니까 직진"하다가 커브에서 선을 놓쳤을 거야.

3센서는 발밑만 보고 걷는 것과 같아. 6센서는 발밑(아랫줄)도 보고 저 앞(윗줄)도 봐. 운전으로 치면, 노련한 운전자는 멀리 커브를 미리 내다보고 부드럽게 핸들을 틀잖아? 6센서 자동차가 딱 그런 운전을 배우는 거야.

상태 암호 = "FL_FC_FR_L_C_R" (6자리)

상태는 6개의 0 또는 1로 되어 있어. 각 자리가 센서 하나야. 1 = 그 센서가 검은 선 위, 0 = 선을 못 봄이라는 뜻.

FL_FC_FR _ L_C_R
└─ 윗줄(미래) ─┘ └─ 아랫줄(현재) ─┘

6자리라서 나올 수 있는 조합은 이론상 2×2×2×2×2×2 = 2⁶ = 64가지야. (실제 주행에서는 그중 자주 나오는 몇십 가지만 쓰여.)

상태 읽기 연습 — 이 표만 봐도 감이 와!

둘째 줄 1_0_0_0_1_0이 6센서의 자랑이야. 발밑은 아직 가운데인데도 앞이 왼쪽이니까 "미리 왼쪽으로 틀자!"를 배워. 3센서는 이걸 못 해서 커브에서 좌우로 흔들렸어. 이게 "지그재그 문제"를 6센서가 해결하는 지점이야.

🧩 상태 읽기 퀴즈

상태가 0_0_1_0_1_0 이야. 윗줄과 아랫줄이 각각 어디를 보고 있고, 무슨 상황일까?

윗줄 = 0_0_1 → 오른쪽. 아랫줄 = 0_1_0 → 가운데. 즉 "발밑은 아직 가운데인데 앞이 오른쪽으로 휜다" = 우커브 진입 예고! 자동차는 미리 우회전을 배우게 돼.

3. 【1단계】 자동차 블록 완전 해부 🔬

이제 진짜 블록을 뜯어보자! 1단계 파일에서 자동차 스프라이트에는 스크립트가 딱 1개 있어. 🏁 클릭했을 때로 시작하는 이 스크립트가 강화학습의 전부야. 크게 준비 단계(딱 한 번) + 학습 루프(무한 반복 6단계)로 나뉘어.

각 블록마다 이 블록 → 하는 일 → 왜 필요 → 초보 팁 순서로 설명할게. 급하면 색깔 박스(🤔왜 / 🍬쉽게 / 💡팁)만 읽어도 돼.

🅐 준비 단계 — 시작하면 딱 한 번만 실행

[ 자동차 ] 스프라이트 — 초록 깃발 직후
🏁 클릭했을 때
학습모드 ▾ 을(를) 0 로 정하기
누적보상 0 / 에피소드 0 / 스텝 0 로 정하기
L 0 / C 0 / R 0 로 정하기
🧠 AI 두뇌 설정 (학습률 0.2, 탐험률 0)
⚙ 시스템 설정 (행동수 3)
x -129 y -138 로 이동 90도 방향 보기 0.3초 기다리기
변수들을 0으로 정하는 이유: 지난번에 달린 점수·횟수가 남아 있으면 이번 연습이 엉망이 돼. 매번 똑같은 출발선에서 시작하려고 점수판을 0으로 초기화하는 거야. 센서값 L·C·R도 깨끗이 비워.
🧠 AI 두뇌 설정이 하는 일: 자동차의 뇌(Q테이블 학습기)를 켜고 성격을 정해. 학습률 0.2 = "경험 하나를 20%만큼 반영". 탐험률 0 = 새 시도 없이 배운 대로만 달림. → 이 파일은 지금 "이미 다 배운 상태로 저장"되어 있다는 뜻!
⚙ 시스템 설정 (행동수 3)이 하는 일: 뇌에게 "선택지는 3개(직진·좌·우)야"라고 알려줘. 이 숫자에 맞춰 Q테이블의 칸이 만들어져. 센서는 6개로 늘었어도 행동은 여전히 3개라 학습 로직은 예전이랑 똑같아.
여기까지는 그냥 게임 시작 준비야. "점수를 0으로 하고, AI 뇌를 켜고, 자동차를 출발선(x −129, y −138)에 90도로 세워놓고, 0.3초 기다리기." 센서들이 자리 잡을 시간을 주는 거지.
여기서 학습모드가 0, 탐험률이 0인 게 보이지? 이 상태로는 절대 학습이 안 돼(배운 대로 달리기만 함). 학습을 시키려면 이 두 값을 바꿔야 하는데, 그 방법은 5장에서 자세히 알려줄게!

🅑 학습 루프 — 무한 반복 속 6단계 (핵심 중의 핵심)

무한 반복하기 안에서 아래 ①~⑥이 쉼 없이 돌아가. 이 여섯 단계가 곧 강화학습 한 사이클이야.

① 지금 상태 보기 → ② 행동 고르기 → ③ 실제로 움직이기 → ④ 새 상태 보기 → ⑤ 점수 매기기 → ⑥ 배우기 ↺

1지금 상태 보기 — 어디 있고, 앞은 어떻게 휘나

현재상태 ▾ 을(를) 👁 6센서 변환: 전 FL FC FR 후 L C R (민감도 50) 로 정하기

하는 일: 6개 센서값을 읽어서 1_0_0_0_1_0 같은 상태 암호를 만들어 현재상태 변수에 저장해.

왜 "변환"이 필요해? 센서값은 원래 0~100 사이의 연속된 숫자야. 그걸 그대로 쓰면 상태 종류가 무한대라 표(Q테이블)로 못 배워. 그래서 민감도 50을 기준으로 "50보다 크면 1, 아니면 0"으로 딱딱하게 나눠(이산화) 6자리 암호를 만드는 거야. 그래야 표에 담을 수 있는 깔끔한 상태가 돼.
왜 "전(前)/후(後)" 두 부분이야? 블록의 전 3칸 = 윗줄(먼 곳=미래), 후 3칸 = 아랫줄(가까운 곳=현재)이야. 이 순서대로 붙여서 FL_FC_FR_L_C_R를 만들어. 그래서 "지금 어디 있나(후)"와 "앞이 어디로 휘나(전)"를 한 상태에 함께 담을 수 있어.
눈으로 "가까운 선은 어디 있고(아랫줄), 저 앞 선은 어디로 휘나(윗줄)"를 보고 1_0_0_0_1_0 같은 암호로 적는 거야. 이 암호가 자동차가 보는 "상황"이야.

2행동 고르기 — 무엇을 할까

행동 ▾ 을(를) 🎯 행동 고르기 (상태 현재상태) 로 정하기

하는 일: 지금 상태를 보고 0(직진)·1(좌)·2(우) 중 하나를 골라 행동 변수에 저장해.

이 블록 속에서 벌어지는 일 (ε-greedy): 확률 ε만큼은 아무 행동이나 랜덤으로(=탐험), 나머지는 Q테이블에서 지금 상태 점수가 제일 높은 행동을(=활용) 골라. 배울 땐 일부러 헤매고, 다 배운 뒤엔 최선만 써.
왜 가끔 일부러 엉뚱한 행동을 해? 늘 "아는 최선"만 하면 더 좋은 길을 영영 못 찾아. 새로운 식당을 안 가보면 단골집이 최고인 줄만 아는 것처럼. 그래서 배울 땐 탐험률 30%로 일부러 새 길을 시도해. 다 배운 뒤 달릴 땐 탐험률 0으로 헤매지 않고 최선만 써.

3실제로 움직이기 — 숫자를 진짜 움직임으로

만약 　행동 = 0　 이라면
5 만큼 움직이기 ← 직진 (조금 더 멀리)
만약 　행동 = 1　 이라면
↺ 왼쪽 6도 돌기 4 만큼 움직이기 ← 좌회전 + 전진
만약 　행동 = 2　 이라면
↻ 오른쪽 6도 돌기 4 만큼 움직이기 ← 우회전 + 전진
0 초 기다리기 ← 센서가 새 위치를 읽도록 아주 잠깐 양보
왜 숫자를 if로 번역해? AI가 고른 건 그냥 숫자 0·1·2야. 이걸 실제 움직임으로 바꿔줘야 자동차가 움직이지. 그래서 "행동이 0이면 직진, 1이면 좌회전…" 하고 통역해 주는 거야.
왜 회전한 다음에 또 앞으로(4만큼) 가? 제자리에서 돌기만 하면 앞으로 못 나가서 선을 따라갈 수가 없어. 그래서 회전 뒤에 꼭 전진을 붙여. 직진은 5만큼, 회전은 4만큼 → 똑바로 갈 땐 살짝 더 빠르게 가는 거지.
"돌기 6도"는 아주 조금씩 트는 거야. 6센서가 커브를 미리 알려주니까, 크게 확 꺾을 필요 없이 작게 여러 번 틀어서 부드럽게 감을 수 있어.
맨 끝의 0초 기다리기는 "쉬는 시간"이 아니야. 자동차가 움직인 걸 센서 스프라이트들이 따라잡아 새 위치를 읽을 시간을 아주 잠깐 양보하는 거야. 이게 없으면 센서가 옛날 위치를 읽어 학습이 꼬여.

4새 상태 보기 — 움직인 뒤 어디로 왔나

다음상태 ▾ 을(를) 👁 6센서 변환: 전 FL FC FR 후 L C R (민감도 50) 로 정하기

하는 일: ①과 똑같은 블록으로 상태를 또 읽어서, 이번엔 다음상태에 저장해.

왜 상태를 또 읽어? 학습하려면 "그 행동을 했더니 어떻게 됐는지"가 필요해. 행동 전(현재상태)과 행동 후(다음상태)를 비교해야 "방금 그 행동이 좋았나 나빴나"를 판단할 수 있거든. 그래서 움직이기 전(①)과 움직인 후(④), 두 번 사진을 찍는 거야.

5점수 매기기 — 잘했나 못했나 (⭐ 설계의 핵심)

이번 행동에 점수(보상)를 줘. 블록은 if-else 트리로 되어 있어서 위에서부터 순서대로 조건을 검사해. 맨 위 조건부터 걸리는 데서 멈춰.

만약 　다음상태 = 0_0_0_0_0_0 또는 벽·가장자리에 닿음　 이라면
보상 = -100 에피소드 +1 출발점(-129,-138,90도)으로 리셋
아니면 ▸ 만약 　C>50 그리고 L<50 그리고 R<50　 (아랫줄 정중앙만!)
보상 = +10 ← 최고! 정확히 가운데
아니면 ▸ 만약 　C>50　 (아랫줄 가운데가 선 위)
보상 = +5 ← 가운데 근처, 잘하고 있음
아니면 ▸ 만약 　(L>50 그리고 행동=1) 또는 (R>50 그리고 행동=2)　
보상 = +5 ← 선 쪽으로 올바르게 꺾음
아니면 (그 외 모든 경우)
보상 = -1 ← 시간 낭비, 작은 벌점
순서조건 (이게 무슨 뜻?)보상왜 이렇게 줄까?
① 선을 완전히 잃음(6센서 전부 0) 또는 벽·가장자리에 부딪힘 −100 가장 나쁜 결과! 크게 벌주고 한 판을 끝내(에피소드 +1, 출발점으로 리셋). 6개가 전부 0이어야 "완전 상실"이야.
② 아랫줄 정중앙만 선 위 (가운데 C는 있고, 좌 L·우 R는 없음) +10 가장 좋은 상태! 선의 정확히 한가운데를 밟고 있다는 뜻이라 최고 점수로 강하게 칭찬해.
③ 아랫줄 가운데가 선 위 (①②에 안 걸린 나머지 중 C>50) +5 완벽한 정중앙은 아니어도 가운데 근처라 잘하고 있음. 중간 점수로 격려.
④ 선이 왼쪽인데 좌회전(L>50 & 행동1) 또는 오른쪽인데 우회전(R>50 & 행동2) +5 "벗어났어도 바르게 돌아오려고 올바른 방향으로 꺾었네!" → 올바른 복귀 행동을 칭찬.
⑤ 그 외 모든 경우 (헛돌거나 엉뚱한 방향) −1 시간만 낭비하는 행동엔 작은 벌점. "빨리 가운데로 와!"라고 재촉하는 셈.
누적보상 에 보상 만큼 더하기 ← 지금까지 받은 점수를 총합에 쌓기
왜 보상 설계가 제일 중요할까? 자동차는 오직 점수를 최대로 받으려고 행동을 바꿔. 즉 우리가 준 점수표가 곧 "목표"가 되는 거야. "정중앙 +10, 선 놓치면 −100" 이렇게 점수를 짜주면 자동차는 "선 한가운데를 유지하며 빠르게 달리기"를 목표로 삼게 돼. 점수를 다르게 주면 자동차의 성격이 완전히 바뀌어!
우리는 운전 방법을 하나도 안 가르쳤어. 그냥 "가운데면 +10, 선 놓치면 −100" 같은 점수 규칙만 줬을 뿐이야. 그런데도 자동차는 점수를 더 받으려고 스스로 가운데로 다니는 법을 익혀. 심지어 6센서라서 커브를 미리 부드럽게 도는 것까지 점수로 배워!

🧩 보상 트리 퀴즈

아랫줄이 가운데(C)와 왼쪽(L) 둘 다 선 위라서 C>50이고 L>50이야. 몇 점을 받을까?

+5점. ②번은 "정중앙만"(L도 R도 없어야) 조건이라 탈락. 대신 ③번 C>50에 걸려서 +5. 트리는 위에서부터 처음 걸리는 곳에서 멈춘다는 걸 기억해!

6배우기 — 여기서 진짜 학습이 일어난다! ⭐⭐⭐

만약 　학습모드 = 1　 이라면
📚 AI 가르치기 (현재상태 현재상태, 행동 행동, 보상 보상, 다음상태 다음상태)
스텝 +1
이 블록이 바로 "진짜 학습"이야! 📚 AI 가르치기 블록이 Q테이블(공부 노트)을 실제로 고쳐 써. "이 상태에서 이 행동을 했더니 이만큼 점수를 받았다"를 표에 반영하는 거지. 이 블록이 없으면 자동차는 아무것도 못 배워!
왜 "학습모드=1일 때만"? 학습모드가 1이면 표를 고쳐 쓰고(배우기), 0이면 이 블록을 건너뛰어(배운 대로 달리기만). 그래서 같은 프로그램 하나로 학습도 하고 주행도 할 수 있어. 스위치 하나로 "공부 모드 ↔ 실전 모드"를 바꾸는 셈이야.
새 점수 = 원래 점수 + 0.2 × ( 받은 보상 + 미래에 좋아질 기대치 − 원래 점수 )
└ 0.2 = 학습률 α. "예상과 실제의 차이(놀람)"만큼만 조금씩 고쳐 쓴다
이 공식은 "예상했던 점수랑 실제로 받은 점수의 차이(놀람)만큼만 표를 살짝(20%) 고쳐 쓴다"는 뜻이야. 놀랄 일이 없어지면(예상=실제) 학습이 다 된 거지. 시험 문제를 틀릴 때마다 오답노트를 조금씩 고치는 거랑 똑같아.
스텝 +1은 "몇 번 반복했나"를 세는 카운터야. 누적보상과 함께 "얼마나 오래, 얼마나 잘 배우는 중인지"를 보여주는 계기판이지.

4. 【1단계】 센서 6개(눈) 블록 👁️

3장의 자동차가 "뇌"라면, 센서 6개는 "눈"이야. 각 센서는 독립된 스프라이트이고, 6개 모두 구조가 똑같아. 그냥 돌리는 각도와 앞으로 나가는 거리만 조금씩 달라.

센서 하나가 하는 일 (예: 센서L)

[ 센서L ] 스프라이트 (나머지 5개도 각도·거리만 다르고 구조 동일)
🏁 클릭했을 때 무한 반복하기
자동차 ▾ (으)로 이동하기 ← 자동차 몸에 딱 붙기
자동차의 방향 보기 ← 자동차랑 같은 방향으로 회전
↺ 왼쪽 15도 돌기 30 만큼 움직이기 ← 앞-왼쪽 가까운 지점으로
만약 　검은색(#000000)에 닿았는가?　 이라면 L = 100 아니면 L = 0
왜 자동차로 이동한 다음 돌고 앞으로 가? 진짜 로봇에서는 센서가 차 앞에 딱 고정돼서 차와 함께 움직여. 시뮬에서도 그걸 흉내 내려고, 매 순간 자동차 위치·방향에 맞춰 센서를 옮긴 뒤 정해진 각도로 돌려 앞으로 내보내서 그 자리를 "스캔"하는 거야.
왜 검은색에 닿으면 100, 아니면 0? 검은 선에 닿으면 100(선 위), 아니면 0(선 밖). 이게 진짜 라인센서(적외선 센서)가 "선을 봤다/못 봤다"를 알려주는 걸 흉내 낸 거야. 3장 ①의 "민감도 50"이 이 100/0 값을 1과 0으로 굳혀 상태 암호를 만들어.

6개 센서 = 이 스크립트를 복제해 3곳만 바꾸기

6개 센서는 모두 위 스크립트를 복사해서 ①돌기 각도 ②앞으로 가는 거리 ③담당 변수 딱 3곳만 바꾼 거야.

각도는 작게, 거리는 멀리: 윗줄(far)은 각도를 좁히고(±9도) 거리를 늘려서(45) 더 멀리 앞을 봐. 그래서 커브의 방향을 먼저 잡아내지. 아랫줄(near)은 각도를 넓히고(±15도) 가까이(30) 두어 차 바로 앞의 현재 위치를 봐.
센서가 자동차 몸 위에 있으면 검은 선 대신 자동차 그림을 봐서 가운데가 안 잡혀. 그래서 ~만큼 움직이기로 차 앞으로 꼭 내보내야 해. (윗줄은 45로 더 멀리 내보내는 이유가 이거야.)
6개 센서는 자동차 앞에 2줄로 촘촘히 박힌 눈이라고 생각하면 돼. 아랫줄 3개는 발밑을, 윗줄 3개는 저 앞을 봐. 이 6개 눈이 매 순간 "선을 봤나 못 봤나"를 자동차의 뇌(3장)에 실시간으로 보고해.

5. 【실습】 자동차를 진짜로 학습시켜 보자! 🎓

지금까지 블록을 다 봤으니, 이제 자동차를 직접 학습시켜 볼 차례야. 저장된 파일은 "주행 모드"(학습모드=0, 탐험률=0)로 되어 있어서 열자마자 잘 달려. 하지만 백지에서 배우는 과정을 보려면 딱 두 곳만 바꾸면 돼!

⚡ 터보로 빠르게 수천 번 반복

깃발을 누른 뒤 터보 모드(⚡)를 켜면 반복이 아주 빨라져. 학습은 수천 번의 시행착오가 쌓여야 하니까 터보로 팍팍 돌려. 처음엔 자동차가 비틀비틀 자주 죽지만, 시간이 지나면 점점 매끄럽게 달려.

터보 켜는 법: 보통 초록 깃발을 Shift+클릭하거나 편집기의 터보 모드 옵션을 켜면 돼. 화면 속 자동차가 눈에 안 보일 만큼 빠르게 연습하는 게 정상이야.

📈 "잘 배우고 있다"는 신호 3가지

① 누적보상 우상향

누적보상이 점점 커지면 점수를 잘 받고 있다는 뜻. 학습의 가장 중요한 신호!

② 에피소드 증가 둔화

에피소드(실패 횟수) 늘어나는 속도가 느려지면 선을 덜 놓친다는 뜻 = 잘 달림.

③ 눈으로 봐도 부드럽게

주행이 덜 흔들리고 커브도 미리 부드럽게 돌기 시작하면 잘 배운 거야.

💾 다 배웠으면 → 주행 모드로 되돌리고 저장

  1. 충분히 배웠다 싶으면 학습모드를 다시 0, 탐험률을 다시 0으로 되돌려. (헤매지 않고 배운 대로만 달리게)
  2. 💾 강화학습 모델 저장하기 블록으로 Q테이블을 JSON 파일로 저장해. 이게 자동차가 배운 "두뇌"야.
  3. 이 JSON 파일을 2단계(실차)로 그대로 가져가면, 진짜 자동차가 배운 대로 달려! (다음 6장)
비유하면, 1단계는 운전면허 시험을 컴퓨터 시뮬로 수천 번 연습하는 거야. 다 익히면 그 "운전 실력(Q테이블)"을 파일로 저장해서, 진짜 자동차에 그대로 옮겨 심는 거지.

😵 자주 겪는 문제 & 해결

이런 일이 생기면원인해결
계속 0_0_0_0_0_0만 나옴센서가 선을 아예 못 봄. 출발 위치가 선에서 벗어났거나 센서가 자동차 몸 위에 있음.출발 위치(−129,−138)와 트랙 정렬 확인. 센서가 차 앞으로 나가는지 확인.
아무리 돌려도 안 늘어남학습모드=0이거나 탐험률=0이라 학습이 안 켜짐.학습모드=1, 탐험률=0.3 둘 다 확인.
너무 느리게 배움반복 횟수 부족.터보(⚡) 켜고 더 오래 돌리기.
배웠는데 저장이 안 됨저장 전에 파일이 초기화됨.깃발을 다시 누르면 준비 단계에서 표가 리셋될 수 있으니, 학습 직후 바로 저장.
깃발을 다시 누르면 조심! 준비 단계에서 변수를 0으로 초기화하니까, 애써 배운 표가 날아갈 수 있어. 배운 직후에 바로 저장하는 습관을 들이자.

6. 【2단계】 진짜 자동차로 옮기기 (Sim2Real) 🚗

드디어 컴퓨터에서 배운 두뇌(Q테이블)를 진짜 자동차에 옮길 시간이야! 파일은 09_2단계_실주행_6센서2줄_v7이고, AI주행 스프라이트 하나로 움직여. (무대 변수는 현재상태·행동·마지막방향 3개뿐이야.)

🧩 오프보드 컴퓨팅 — 눈·뇌·다리를 나눈다

진짜 자동차엔 강력한 컴퓨터를 못 실어. 그래서 역할을 3개로 나눠 협력해:

👁️ 눈 = ESP32캠

자동차에 달린 작은 카메라. 바닥의 선을 촬영해 무선으로 컴퓨터에 보내.

🧠 뇌 = PC (브릭셀AI)

카메라 영상을 보고 Q테이블로 행동을 결정. 무거운 계산은 여기서.

🦵 다리 = 우노카

PC가 내린 명령대로 바퀴(서보)를 굴리는 진짜 자동차 본체.

눈이 본 것 → 뇌가 결정 → 다리가 실행. 이 셋이 무선으로 계속 주고받으며 달려.

🖱️ 주행 전에 버튼 3개를 순서대로 클릭

깃발을 누르기 전에, 눈·다리·뇌를 차례로 준비시켜야 해.

🔑 전이의 비결 — 카메라 6영역 = 시뮬의 6센서

어떻게 시뮬에서 배운 두뇌가 진짜 자동차에서 통할까? 비밀은 "똑같은 6센서 변환 블록"을 쓰는 거야!

현재상태 ▾ 을(를) 👁 6센서 변환: 전 카메라 먼-좌 먼-중 먼-우 후 근-좌 근-중 근-우 (민감도 0.5) 로 정하기
시뮬에선 6개 센서가 "검은색에 닿았나"로 100/0을 만들었지? 실차에선 카메라 화면을 6칸으로 나눠, 각 칸에 선이 있나 없나로 똑같이 0/1을 만들어. 입력만 (색감지 → 카메라)로 바뀔 뿐, 결과 상태 암호가 똑같이 0_1_0_0_1_0 6자리라 배운 Q테이블이 그대로 통하는 거야! 이게 Sim2Real의 마법이야.

8. 스스로 점검 & 한 줄 요약 ✅

📋 이해했나 체크리스트 (다 체크되면 완전정복!)

  • 강화학습은 정답 대신 보상(점수)으로 스스로 배운다는 걸 안다.
  • 상태 암호 FL_FC_FR_L_C_R에서 앞 3자리=미래(윗줄), 뒤 3자리=현재(아랫줄)임을 안다.
  • 1_0_0_0_1_0이 "곧 좌커브"라 미리 좌회전을 배우는 이유를 설명할 수 있다.
  • 학습 루프 6단계(상태→행동→움직임→새상태→보상→배우기)를 순서대로 말할 수 있다.
  • 보상 트리에서 정중앙 +10, 선 놓침 −100 등 각 조건의 뜻을 안다.
  • 📚 AI 가르치기 블록이 "진짜 학습"(Q테이블 갱신)이라는 걸 안다.
  • 학습시키려면 학습모드=1 + 탐험률=0.3 둘 다 바꿔야 함을 안다.
  • 실차 전이의 비결이 "똑같은 6센서 변환 → 똑같은 상태 암호"임을 안다.
  • 회전을 전진 호로 하고 정지 블록을 빼는 이유(부드러운 주행)를 안다.

🎯 한 줄 요약 4가지 — 이것만은 꼭!

1️⃣ 강화학습 = 정답을 안 알려주고, 보상(점수)만 줘서 AI가 스스로 잘하는 법을 터득하게 하는 것.
2️⃣ 6센서 2줄 = 아랫줄(현재)+윗줄(미래)로 커브를 미리 읽어 부드럽게 도는 것.
3️⃣ 진짜 학습은 📚 AI 가르치기에서 일어나고, 켜려면 학습모드=1·탐험률=0.3.
4️⃣ Sim2Real = 똑같은 6센서 변환 덕분에 시뮬에서 배운 Q테이블이 진짜 자동차에서도 통하는 것.
여기까지 다 읽었다면 넌 이제 강화학습 자율주행의 전체 그림을 이해한 거야. 처음 들어봤다던 그 강화학습을, 블록 하나하나까지 완전정복했어. 이제 직접 자동차를 학습시키고 진짜로 달리게 해보자! 🚗💨
